# Bike Mileage & Maintenance App (Expo)\n\nThis is a small Expo React Native app to:\n- Record odometer readings, compute distances between entries.\n- Remind you daily at 10:00 PM to log mileage.\n- If you don't log, it will remind every 15 minutes that evening until you log (the app schedules those reminders ahead).\n- Record services (engine oil change, tuning, maintenance, depreciation) and intervals.\n\nHow it works:\n- Local SQLite database is used to store entries and scheduled notification ids.\n- On first run (or app start) the app requests notification permissions and schedules reminders for the next 30 days:\n  - A notification at 22:00 daily.\n  - 15-minute follow-ups that same evening (22:15, 22:30, ... 23:45) for each day.\n- When you save a mileage entry for today the app cancels remaining scheduled reminders for today's date.\n\nSetup:\n1. Install Expo CLI (if you don't have it): `npm install -g expo-cli`\n2. Install dependencies: `npm install`\n3. Run: `expo start` and open on a device (notifications won't work reliably on simulators; use a real device)\n4. Allow notifications when prompted.\n\nNotes & limitations:\n- This is a device-local app. If you need cloud sync or cross-device pushing, we should add a backend (Firebase/FCM or similar).\n- The scheduling strategy schedules explicit notifications for the next 30 days. If you want a different policy (e.g., server-driven reminders, dynamic scheduling), I can adapt it.\n- On iOS, background scheduling and exact minute guarantees are subject to OS policies. This approach is reliable on most Android devices and generally works on iOS for local notifications scheduled at specific dates.
